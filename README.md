# thakay.github.io

The GitHub Pages user site behind `data.thakay.dev`. It holds no content of its own: the root redirects to [blog.thakay.dev](https://blog.thakay.dev/).

Every repository of this account that publishes GitHub Pages is served under this domain at `data.thakay.dev/<repo>/`. For example, [Thakay/ste-eval](https://github.com/Thakay/ste-eval) publishes its `docs/` folder at `data.thakay.dev/ste-eval/`.

To publish a new interactive page with a post: put it in the repo's `docs/` folder, turn on Pages for that repo (branch `main`, folder `/docs`), and link to `data.thakay.dev/<repo>/` from the post. The repo name becomes the path, so choose it with that in mind.
